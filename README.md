# Educrust-LMS

## Description
Educrust-LMS is a Learning Management System designed to facilitate online education.

## Features
- Course management
- User registration and management
- Assignment submission
- Progress tracking
- Communication tools

## Tech Stack
- **Frontend:** React.js
- **Backend:** Node.js, Express
- **Database:** MongoDB
- **Deployment:** Heroku

## Installation
To install the project, clone the repository and install the dependencies:
```bash
git clone https://github.com/navanithaadhav/Educrust-LMS.git
cd Educrust-LMS
npm install
```

## Setup
Set up your environment variables in a `.env` file. Refer to `.env.example` for required variables.

## Project Structure
```
Educrust-LMS/
├── client/             # Frontend application
├── server/             # Backend application
└── README.md           # Documentation
```

## Running the Application
To run the application, start the server and the client:
```bash
# Start the server
cd server
npm start

# Start the client
cd client
npm start
```
